## 📦 How to Deploy on GitHub Pages

1. **Create a new GitHub repository** (e.g. `portfolio` or `karri-prasad-portfolio`)

2. **Upload `index.html`** (and this README) to the repo root

3. **Enable GitHub Pages:**
   - Go to your repo → **Settings** → **Pages**
   - Under **Source**, select `Deploy from a branch`
   - Choose `main` branch, `/ (root)` folder
   - Click **Save**

4. Your site will be live at:
   ```
   https://<your-github-username>.github.io/<repo-name>/
   ```

## ✏️ Customization

All content is in `index.html`. Key things you might want to update:

- **LinkedIn URL** — search for `shyamkarri` and replace with your actual LinkedIn handle
- **GitHub URL** — search for `shyam-karri` and replace with your actual GitHub username
- **Phone / Email** — already populated from your resume
- **Profile photo** — add an `<img>` tag in the hero section if you'd like a photo
